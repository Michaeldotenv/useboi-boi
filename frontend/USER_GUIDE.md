# User Dashboard - Quick User Guide

## 🎯 Main Features

### 1. Global Search
**Location**: Main dashboard search bar (top of page)

**How to use**:
1. Type any item name in the search bar (e.g., "stir-fry spaghetti")
2. Results appear automatically as you type
3. See how many results were found
4. Click any item to view the vendor's full menu

**Search covers**:
- Item names
- Item categories
- Item descriptions
- All vendors in the system

### 2. Browse Stores
**Location**: Main dashboard

**How to use**:
1. Scroll through the store carousels:
   - "Buy again" section
   - "Vendors near you"
   - "Best deals for you"
   - "More stores"
2. Click any store card to view store details
3. From store details, click "Browse items" to see all items
4. Use category filter to narrow down items

### 3. Category Filtering
**Location**: Store items page

**Features**:
- Filter by category dropdown
- Filter by price range
- Sort by name or price
- Search within store items
- Clear all filters button

### 4. View Orders
**Location**: Bottom navigation bar → Orders tab

**Features**:
- See all your orders
- View order status
- Click "View" to see order details
- Track order progress

### 5. Saved Stores
**Location**: Bottom navigation bar → Saved tab

**Features**:
- View all your saved/liked stores
- Quick access to favorite vendors
- Remove stores from saved list

## 🗺️ Navigation Map

```
Main Dashboard
│
├─ Search Bar → Search Results → Vendor Items Page
│
├─ Store Cards → Store Details → Browse Items → Items with Filters
│
├─ Category Grid → Filtered Stores → Store Details
│
└─ Bottom Nav
   ├─ Explore (Home)
   ├─ Saved (Favorites)
   ├─ Orders (Order History)
   ├─ Support (Help)
   └─ Profile (Settings)
```

## 💡 Pro Tips

1. **Quick Search**: Start typing in the search bar to instantly find items across all stores
2. **Filter Smart**: Use the category filter in the items page to quickly find what you need
3. **Save Favorites**: Like stores you frequently order from for quick access
4. **Check Orders**: Track your order status in real-time from the Orders tab
5. **Browse Categories**: Use the category grid on the home page to explore specific types of stores

## 🔄 Navigation Shortcuts

- **Back to Home**: Click "Back" button or "Explore" in bottom nav
- **Clear Search**: Delete text in search bar to return to main view
- **Quick Store Access**: Click any store card anywhere to view details
- **Direct to Items**: From search results, click item to go directly to vendor's menu

## 📱 Mobile-Friendly Features

- Swipe through store carousels
- Touch-friendly buttons and cards
- Responsive search bar
- Easy-to-tap navigation
- Smooth animations and transitions

## 🎨 Visual Indicators

- **Purple/Pink**: Primary actions and branding
- **Green Badge**: Store is open
- **Star Rating**: Store/item quality indicator
- **Distance**: How far the vendor is from you
- **Price**: Displayed in Nigerian Naira (₦)

## 🚀 Getting Started

1. **First Time**: Browse the main dashboard to see available stores
2. **Search**: Try searching for your favorite food
3. **Explore**: Click on stores to see their menus
4. **Order**: Select items and proceed to checkout
5. **Track**: Monitor your order in the Orders tab

## 📞 Need Help?

- Navigate to Support tab in bottom navigation
- Submit a support ticket
- View your ticket history
- Get assistance with orders or technical issues
